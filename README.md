# Evaluation

This folder contains the materials for the user evaluation of the three main visualizations.

## Contents

- `task_description.md`: setup of the study, method, procedure, and participants.
- `survey_form.md`: the questions that were asked during each session.
- `P1_notes.md` to `P4_notes.md`: anonymised notes from each participant.

A synthesis of the findings and the resulting design changes is documented in Section 4 (Evaluation) and Section 5 (Design Improvements) of the project report.
